# 🚀 Быстрый запуск CodeReview Bot

## 1. Подготовка (5 минут)

### Получите токен бота:
1. Откройте @BotFather в Telegram
2. Отправьте `/newbot`
3. Придумайте имя и username для бота
4. Сохраните токен

### Получите ваш Telegram ID:
1. Откройте @userinfobot в Telegram  
2. Отправьте `/start`
3. Сохраните ваш ID

## 2. Развертывание на сервере (10 минут)

```bash
# Подключитесь к серверу
ssh root@85.198.83.158

# ВАЖНО: Сначала смените пароль root!
passwd

# Скачайте и распакуйте проект
cd /opt
# Здесь нужно скопировать файлы проекта на сервер

# Перейдите в директорию проекта
cd codereview-bot

# Запустите установку
./scripts/server_setup.sh

# Настройте конфигурацию
cp .env.example .env
nano .env
```

В файле .env измените:
- `BOT_TOKEN` = токен от BotFather
- `ADMIN_TG_ID` = ваш Telegram ID  
- `DB_PASSWORD` = придумайте пароль

```bash
# Запустите бота
./scripts/deploy.sh
```

## 3. Проверка работы (2 минуты)

1. Найдите бота в Telegram по username
2. Отправьте `/start`
3. Создайте первую команду: `/admin_create_team Developers`

## 4. Добавление пользователей

```bash
# Пользователь должен сначала написать боту /start

# Затем администратор добавляет его в команду:
/admin_add_user 123456789 Developers
```

## 📱 Основные команды

**Для администратора:**
- `/admin_create_team <название>` - создать команду
- `/admin_add_user <tg_id> <команда>` - добавить в команду
- `/admin_set_team_leader <tg_id> <команда>` - назначить тимлида

**Для пользователей:**
- `/start` - начать работу
- `/request_review` - запросить ревью
- `/my_teams` - мои команды

## 🆘 Если что-то пошло не так

```bash
# Посмотрите логи
docker-compose logs -f bot

# Перезапустите бота
docker-compose restart

# Проверьте статус
docker-compose ps
```

## 💡 Подсказки

1. Токен бота начинается с цифр и содержит двоеточие
2. Telegram ID - это число (обычно 9-10 цифр)
3. Пользователи должны сначала запустить бота, потом их можно добавлять
4. В команде должно быть минимум 2 активных разработчика для работы ревью
